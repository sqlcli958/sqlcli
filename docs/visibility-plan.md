# Visibility rollout plan

This repository is newly public. Prioritize conversion quality before broad promotion.

## Phase 1 — discoverability and trust

- English-first homepage with Chinese mirror
- clear AI-agent/database keywords
- product screenshot and schema-graph visual
- CI, release automation, issue templates, contribution and security docs
- direct getting-started path

## Phase 2 — distribution

- publish the first reviewed GitHub Release
- add repository Topics and optimized About description
- configure a social preview image
- enable Discussions when maintainers can actively respond

## Phase 3 — external discovery

Publish technical content around the underlying problem rather than generic project announcements. Good themes include:

- why AI agents generate SQL that is syntactically valid but semantically wrong
- grounding agents with schema metadata, business terms, value domains, and verified joins
- safe write execution with human approval, audit, and recovery SQL

Link readers to a concrete demo and the latest GitHub Release.

## Future product surface

An MCP adapter could broaden compatibility with additional coding agents and IDEs. Add MCP-related repository topics only after that adapter exists and is documented.
