# 软件著作权申请材料包

本目录按“个人独立开发、先申请软著、后续逐步开源”准备。

## 当前拟申请信息

| 字段 | 暂定内容 | 提交前动作 |
|---|---|---|
| 软件全称 | SQL CLI 多数据库安全查询与管理软件 | 如平台要求英文名，保持与源码页眉一致 |
| 软件简称 | SQL CLI | 确认是否使用简称 |
| 版本号 | V1.0 | 从 `1.0.3-SNAPSHOT` 固定出一个稳定版本后确认 |
| 著作权人 | `[待填写：本人姓名]` | 必须与身份证姓名完全一致 |
| 开发者 | `[待填写：本人姓名]` | 个人独立开发时通常与著作权人一致 |
| 开发完成日期 | `[待填写：YYYY-MM-DD]` | 按拟申请版本实际完成日期填写 |
| 首次发表状态 | 未发表 | 如果已经公开仓库或发布安装包，改为已发表并填写日期 |

## 文件说明

- `01-申请表字段草稿.md`：在线申请表的填报底稿。
- `02-软件说明书.md`：可整理为申请用软件文档。
- `03-权属声明模板.md`：个人独立开发声明，补齐个人信息后签名。
- `04-源程序交存准备.md`：源代码选取、排除项和提交前检查。
- `05-核心亮点提炼.md`：10 个核心亮点，按三大核心问题（辅助 Agent 设计数据库、辅助 Agent 分析数据、Agent 与人共同维护可靠图谱）组织，可直接引用到申请表"软件功能和技术特点"。

## 提交前必须补齐

1. 本人姓名、身份证号、联系地址、电话和电子邮箱。
2. 软件最终名称、版本号、开发完成日期和首次发表状态。
3. 申请版本的干净源码快照，不要直接使用当前含大量未提交改动的工作区。
4. 源码中的软件名称、版本号和申请表保持一致。
5. 个人签名及平台要求的日期。

## 重要边界

本材料包只描述和提交本项目自有源码。Maven/npm 依赖、JDBC 驱动、构建产物、`node_modules`、`target` 和真实数据库配置不属于申请源码材料。
